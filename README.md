# Filum — 561 Group's Section Newswire Cable

Filum is a **shared, source-qualified cable of Newswires**, not a single
undifferentiated news feed. Every actual 561 Group service-section has a
potential distinct wire: its name and source custody derive from the original
section repository, not from an agent guessing a topical keyword.

## The section-wide product

The established [NewsCable domain model](https://github.com/emsenn/news-topology/blob/main/src/cable.mts)
distinguishes a wire (one original stream/identity) from a cable (a common
directory, route and process). The intended current projection is:

- `filum.561.group` — the common cable and machine discovery surface
- `<section-name-without-services-section>.filum.561.group` — one wire per
  source-owned section, after its original Newsroom/public receiving succeeds
- Each admitted wire publishes its **own** HTML, RSS 2, Atom, JSON Feed,
  original published data, PROV-O/metadata and independently receivable source
  editions using the original Newswire/Web publishers
- Qualified paid topic, source, time, data-field and historical/edition
  retrieval is sold **only by the original 561 x402 merchant**. The section
  owner supplies the use and acceptance requirements; the merchant controls
  price/payment/settlement. Publishing an RSS feed never by itself grants
  resale rights.

For example, the public candidate names in
[data/records/filum-section-cable-policy.json](data/records/filum-section-cable-policy.json)
are `predicate-science.filum.561.group`,
`specification-engineering.filum.561.group` and
`group-operations.filum.561.group`. These are **uninstalled reservations,
NOT live hosts, working feeds or offers**. The complete October 24
GitHub App repository observation identifies these three public-source
Science, Engineering and Operations sections separately. It adds later
observations to the earlier pinned October 22 source without rewriting
the original historical record. No private repository names are released
by this Causeway public policy.

The same engineering compiler identifies matching Science/Engineering/
Operations triplets (for example, subject-specific Science research,
Engineering change/evidence, and Operations received effects) from the
original Group census. The three wires retain separate editorial identities
and can eventually be federated into buyer-specific cross-section queries
without treating knowledge, implementation and operating results as one
assertion. An organization chart is **not** evidence that the three streams
contain live or saleable material.

## Source and receiver ownership

This **Public Filum section holds only public instance data and publication
terms**. Executable code lives in the existing
[Red Cup Newswire Engineering Section](https://github.com/red-cup-engineering/newswire-engineering-services-section),
not here. Its `src/section-filum.mjs` admits the Group's original
Git-blob-verified [dated GitHub repository census](https://github.com/561-group/561-group-services-section/blob/main/data/records/github-whatever-service-records/manifest.json)
and its independently received current **October 24 five-installation
source**, deriving a potential wire for each canonical section. The older
source records 441 candidate sections; the newer complete source has **597
actual candidate sections (240 public-source), three complete subject
triads and no hostname collisions**. Neither source confers a public
publication right. Its `src/section-filum-host.mjs` composes **the existing NewswireService** under
section-specific Host names; it does not invent another RSS serializer,
Newsroom, payment actor, or HTTP listener. The original Web Server must
install the trusted-host dispatcher and independently receive DNS/TLS routes.

The source data belongs to its source office; a wire's admitted public packet
belongs to the original Newsroom and its public release authority. The
existing [Rete Agentium Filum](https://github.com/emsenn/rete-agentium-filum)
is a specific topical Newswire under the same larger Filum idea. The
[Public Newswire Section](https://github.com/causeway-services/public-newswire-services-section)
also owns the preexisting Turntide placement wire, which distributes
already published house news to a particular recipient. Neither is replaced
or automatically reclassified as a section-wide public feed by this work.

## Exact installation and commercial rules

A dated census observation proves only that a repository was observed.
It is **not** proof of current repository existence, ownership standing,
privacy consent, section data authority, source feed acquisition,
Newsroom editorial acceptance, DNS or TLS, or an x402 offering. The public
policy's pilots stay `uninstalled`; private sections remain undisclosed
unless a separate original owner/authority explicitly releases their name
and source in public.

Engineering's `inspect-section-filum.mjs` reads the complete original
census checkout through **every source-pinned Git blob**, applies this
[typed source policy](schemas/filum-section-cable-policy.schema.json),
and can write a private candidate plan outside the published repository.
Public projection contains only the policy's public pilot names and
independently approved release grants. Unknown names, name collisions,
custody-phase mismatches, unadmitted source arrivals or unauthorized rights
are held—not silently published.

A release grant requires separately received original newsroom, provenance,
rights and (where necessary) private-section disclosure receipts. Only
then can the original Newswire host fetch that exact section's approved
`newsroom-claim-sets.json`. The host's free cable directory reports *its
actual loaded public streams*, not just configured instances; an unknown
`*.filum.561.group` host must never fall back to another wire or the hub.
Independent HTTPS probes and current customer acceptance are still necessary
before advertising actual public availability.

A **commercial** grant further requires an independently admitted original
merchant offer, legally qualified source use, a real live 402 quote on the
correct route, payment rail and payee, recoverable delivery, economic
cost/fees and a successfully received outside buyer result. Shop presents
single-seller services, Bazaar supports multi-provider purchases and Market
organizes economic intelligence and direct eligible purchases. External
Bazaars may index only genuine original merchant endpoints. No guessed
prices, wallets, licenses, sales or sample revenue are configured here.

## Existing historical state

The old Filum application treated `/newswires/<name>/` as the cable route.
That legacy package is marked **decommissioned/triage** in this repository.
This source-owned section policy does not resurrect that old executable
application or assert a production cutover. The next installation must
reconcile its actual hosting and redirects with the existing server and
source-owned routes, preserving any existing public wire identities.

This is an operational foundation for a **wire per section**, not a claim
that every intended subdomain already resolves.
